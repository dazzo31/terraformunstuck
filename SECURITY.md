# Security and privacy

Do not submit tokens, real state, saved plans, private infrastructure identifiers or unredacted logs in public issues. Use a synthetic reproduction. Do not open a public issue containing exploit details or personal information; use GitHub’s private vulnerability reporting if enabled for the destination repository, or a verified private channel with the repository owner.

The website must not transmit, persist or export analyser input. It renders input as escaped text. Only theme, mode and explicitly marked lesson progress may be saved locally. No execution of pasted commands or cloud account connectivity is in scope.

The host may log normal asset requests and enforce site access. External official-documentation links navigate to those services only when selected.
